SUBJECT: COMPUTER SCIENCE & SOFTWARE ENG. • BOOKLET CODE: 01-CS
INSTRUCTIONS: This examination paper contains 100 questions. Choose the single best alternative and bubble your answer sheet carefully. Scientific calculators are permitted. Rough computational work must remain within margin boundaries.
1.

Which of the following data structures provides O(1) average time complexity for both insertion and search operations?

verified Section 1: Algorithms & Data Structures • Domain Weight: 20%
Correct Answer: (B) Hash Table. In a hash table with uniform distribution and a well-engineered collision resolution mechanism (such as separate chaining or open addressing), hash lookups and key insertions operate at constant time O(1) in the average case. Worst-case degenerate clustering degrades to O(n).
2.

In the relational database model, which normal form (NF) specifically eliminates transitive dependencies for non-prime attributes?

verified Section 3: Database Systems • Domain Weight: 20%
Correct Answer: (C) Third Normal Form (3NF). A relation schema is in 3NF if it is already in 2NF and no non-prime attribute is transitively dependent on the primary key (X → Y and Y → Z, where Z is non-prime).
3.

During process management in modern operating systems, which state transition occurs when a process is preempted by the scheduler due to time quantum expiration?

verified Section 5: Operating Systems • Domain Weight: 20%
Correct Answer: (A) Running → Ready. Round-robin scheduling interrupts active CPU execution once the quantum timer expires; the process remains fully runnable and returns to the ready queue.
4.

In the OSI Reference Architecture, at which layer does flow control, segmentation/reassembly, and end-to-end error checking (via TCP) take place?

verified Section 4: Computer Networks • Domain Weight: 15%
Correct Answer: (B) Transport Layer (Layer 4). The transport layer ensures complete and reliable host-to-host delivery via protocols such as TCP, managing windowing, flow control, and segment sequencing.
