In modern multi-threaded operating systems, when multiple processes compete for a shared resource without adequate synchronization primitives, a race condition can occur. verified Faculty Verified Solution Rationale
Authored by Department of Computer Science, Addis Ababa Institute of Technology (AAiT)

Core Synchronization Concept: A semaphore is a synchronization tool provided by the operating system kernel. To avoid the classical CPU-wasting spinlock (busy-waiting) behavior associated with basic hardware instructions like TestAndSet(), modern OS implementations redefine semaphores using a blocking model.

When a thread invokes wait(S) and finds the semaphore value is non-positive, it suspends itself via the kernel-level block() operation. The OS moves the thread to the waiting queue associated with semaphore S and sets its process state to WAITING, relinquishing CPU cycles to other ready processes.

When another process issues signal(S), it removes an entry from the waiting queue and invokes wakeup(), transitioning it back to READY. Hence, mutual exclusion is preserved with zero CPU spinlock waste.

Curriculum Citation: Silberschatz, Galvin & Gagne, Operating System Concepts (10th Ed.), Chapter 6: CPU Synchronization, §6.5–6.6.
